# S07 - Priorización de actividades y anuncio de reunión con SERNAGEOMIN

**Fecha:** 24-09-2026
**Participantes:** BENJAMÍN JARPA, SEBASTIÁN MEDALLA, CÉSAR OLIVARES, PABLO TRONCOSO 

**Responsable del registro:** CÉSAR OLIVARES


## Objetivo

Priorizar las actividades relacionadas con el proyecto y registrar el anuncio de una próxima reunión con SERNAGEOMIN para aclarar dudas sobre la problemática.


## Actividades realizadas

1. Se organizó una visita del curso al Hub de Providencia.
2. El equipo decidió no asistir, al considerar que, según la información disponible, la actividad no tenía una relación directa con las necesidades actuales del proyecto.
3. Se recibió información sobre una próxima reunión con SERNAGEOMIN.
4. Se identificó esta reunión como una oportunidad para aclarar dudas y obtener antecedentes relevantes para PluvioTech.


## Resultados

- El equipo no participó en la visita al Hub de Providencia.
- Se tomó conocimiento de una futura reunión con SERNAGEOMIN.
- Se reconoció la necesidad de preparar las consultas del equipo para aprovechar esa instancia.


## Decisiones y justificación

| Decisión | Evidencia o criterio | Consecuencia para el proyecto |
|---|---|---|
| No asistir a la visita al Hub de Providencia | El equipo estimó que la actividad no respondía directamente a sus necesidades actuales de información y herramientas | No se obtuvieron antecedentes de esa visita |
| Priorizar la preparación para la reunión con SERNAGEOMIN | Se considera una entidad relevante para aclarar dudas sobre el desafío | Se deberán organizar las preguntas y los vacíos de información del proyecto |


## Errores, dificultades o riesgos

- Al no asistir a la visita, no fue posible comprobar directamente si existían recursos o contactos útiles para el proyecto.
- La utilidad de la reunión con SERNAGEOMIN dependerá de contar con preguntas claras y priorizadas.


## Aprendizajes

- Las actividades deben evaluarse según su relación con las necesidades del proyecto, sin descartar que puedan ofrecer aportes indirectos.
- El contacto con actores vinculados al problema puede ayudar a revisar supuestos y orientar las siguientes decisiones.
